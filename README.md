CampusGate Pro — Prototype

CampusGate Pro is a CCTV-free mobile campus entry and exit management system.

Features:
- Digital person and vehicle entry
- Number plate OCR demonstration
- Person details and photo capture interface
- Entry and exit time tracking
- Student, Staff, Visitor, Vendor and Vehicle categories
- Security alerts
- Digital records
- CSV export

How to run:
1. Open index.html in Google Chrome or Microsoft Edge.
2. Go to New Entry.
3. Click Capture Plate + OCR.
4. Enter person details.
5. Click Record Entry.
6. Go to Records to view the entry.
7. Go to Exit and search the plate/name.
8. The system calculates the time spent inside.

Prototype note:
This is a front-end demonstration prototype. The full proposed system can use Flutter, Firebase Firestore, Firebase Storage, Firebase Authentication and Google ML Kit/EasyOCR.
